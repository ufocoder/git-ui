Safer discard of uncommitted changes

- Discard changes to a file, folder or selected files from the Changes toolbar or file context menu, including staged changes.
- A recovery copy is saved to Stash before reverting. Open it directly after the operation to inspect or restore the changes.
- Files changed after confirmation are protected from outdated requests. Renamed, added and deleted files are supported while unrelated changes stay intact.

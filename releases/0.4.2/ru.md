Улучшена производительность

- Ускорены повторный поиск истории и переход между страницами. Устаревшие поисковые запросы отменяются.
- Большие diff прокручиваются плавнее: отображаются только видимые строки.
- Ускорены выбор папок и staging в проектах с большим количеством изменённых файлов.
- При загрузке изменений папки текущий файл сохраняет положение на экране.
- Повторное открытие diff ускорено благодаря кешу. Изменение файлов или staging сбрасывает соответствующий кеш.
- Подсветка результата конфликта создаётся только для видимой области, снижая нагрузку на больших файлах.
